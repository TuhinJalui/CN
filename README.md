# AETHER//GAP — Acoustic Air-Gap Laboratory

An interactive, browser-based research instrument for an FSK acoustic air-gap bridge. It turns a payload into framed bits, synthesises 2-FSK symbols, sends them through a modelled acoustic channel, detects tones with a Hann-windowed FFT, decodes bits, and verifies the frame with CRC-16/CCITT.

Everything shown is generated by the local model or configured by the user. No microphone is opened, no audio is emitted, and no measured results from a paper are reproduced.

## Run

```bash
npm install
npm run dev
```

Open the URL printed by Vite (the local dev server is normally `http://127.0.0.1:5173/`).

```bash
npm run build     # type-check + production build
npm run preview   # serve the production build
```

## What is inside

- **Operations** — air-gap topology, live FSK waveform, receiver FFT, oscilloscope, protocol stack, data-flow timeline, packet/CRC inspector, jamming lab, handshake, presentation mode.
- **Signal Lab** — full-width modulator, near-ultrasonic band view, modelled hardware response, frequency domain, oscilloscope, packet assembly.
- **Experiment** — synthetic BER/PER/throughput/latency sweep across SNR, driven by the same FSK + FFT path.
- **Steganography** — conceptual cover + hidden-symbol layer visualisation, explicitly not an encoder or deployment tool.
- **Defense** — conceptual threat path and mitigation matrix; percentages are illustrative interface weights, not measured efficacy.
- **3D Lab** — WebGL orbit view of the transmitter, receiver, wavefronts and acoustic particles, driven by the same live simulation state.

## Model notes

- Defaults: `AIRGAP`, 44.1 kHz sample rate, 18/20 kHz carriers, 12.5 ms symbols, 24 dB target SNR, 1.8 m.
- Frame: preamble + length + payload + CRC-16/CCITT.
- Per-symbol synthesis includes modelled noise, distance loss, multipath, AGC, speaker/microphone response and optional OS processing.
- The FFT path is deterministic for a given run seed, so CRC decisions are reproducible.
- Jamming is a modelled, authorised-laboratory-only scenario.

## Scientific boundary

- The 18–21 kHz region is **near-ultrasonic / high-frequency audio**, not guaranteed inaudible.
- “Inaudible”, “secure”, “undetectable” and similar terms are not universal claims; perception and detection depend on level, hardware, distance, room and listener.
- All BER, PER, SNR, latency, throughput, CRC and hardening values are **SIMULATED**, **CONCEPTUAL**, **USER-CONFIGURED** or **ILLUSTRATIVE**.
- This project is an architecture visualisation and teaching model, not an offensive tool and not empirical evidence.

## Stack

React 19 + TypeScript + Vite, raw Three.js with OrbitControls, hand-built Canvas 2D and SVG charts. No chart library.
